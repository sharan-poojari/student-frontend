# Student Management System — Frontend

A React.js frontend for a full-stack Student Management System, integrated with a Node.js and Express.js backend.

## Features

- User login and authentication
- JWT-based authentication
- Protected application access
- Role-based user interface
- Student CRUD operations
- User-specific student management
- REST API integration
- Loading and error handling
- Logout and token handling

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- REST APIs
- Fetch API

## Backend

The frontend connects to a Node.js and Express.js backend API with MongoDB and JWT authentication.
